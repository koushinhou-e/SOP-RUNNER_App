# 构建作业助手 v2 / 構築作業アシスタント v2

完全离线、只在本机运行的“构建作业”辅助工具：Excel 交付物模板检测与填写、输入检查、参数表比对、只读确认命令生成、Word 手顺书逐步执行（v1 SOP Runner）。
完全オフライン・ローカル専用の構築作業支援ツールです。Excel 成果物テンプレートの入力欄検出と自動記入、入力チェック、パラメータシート照合、読み取り専用の確認コマンド生成、Word 手順書のステップ実行（v1 SOP Runner）を 1 つにまとめています。

> 本仓库只包含通用代码和**虚构的示例数据**（example.local / 192.0.2.x / 198.51.100.x / 假 ID）。请勿提交真实的模板、参数表或作业数据（`data/` 已在 `.gitignore` 中排除）。
> このリポジトリには汎用コードと**架空のサンプルデータ**のみ含まれます。実際のテンプレート・パラメータシート・作業データはコミットしないでください（`data/` は `.gitignore` 済み）。

## 中文说明

### 运行要求
- Windows 10/11（macOS / Linux 也可），**Python 3.8 及以上**（不需要管理员权限，不需要 `pip install`）
- 浏览器：Edge / Chrome / Firefox 任一
- 不需要网络。程序只监听 `127.0.0.1`，不访问任何外部地址。

### 启动
1. 从 GitHub 下载 ZIP 并解压（或 `git clone`）。
2. Windows：双击 **`start.bat`**。macOS：双击 `start.command`。Linux：`./start.sh`。
3. 浏览器会自动打开 `http://127.0.0.1:8765/`（端口被占用时自动换一个，地址显示在黑色窗口里）。
4. 结束：点击页面右上角「退出」，或在黑色窗口按 `Ctrl+C`。

命令行参数：`python app.py --port 8765 --data-dir D:\work\ba-data --no-browser`

### 使用流程
1. **模板库**：上传
   - 交付物模板（客户的 .xlsx 输出模板）→ 自动检测要填写的单元格
   - 参数表（.xlsx，行 = 参数，列 = 服务器）
   - 手顺书（.docx）
   - 命令模板集（新建或导入 JSON）
   - 也可以先点「加载示例数据（虚构）」体验。
2. **编辑交付物模板**：选择「参照参数表」→「按标签自动映射」。在表格里调整每个检测项：标签、类型（文本/数字/下拉/日期）、选项、必填、格式（IP、实例ID 等）、正则、最小/最大、填充来源（作业输入 / 参数表的键 / 固定值 / 不填）。点击上方网格的单元格可以添加漏检的项目。最后「保存」。
3. **作业**：新建作业，选择模板、参数表、服务器（参数表的列）、命令模板集、手顺书。
   - ① 输入检查：填写作业输入，不符合规则的值实时显示为红色。参数表的值也会按同样规则检查。
   - ② 命令生成：用参数表的值替换 `{{键}}`，生成只读确认命令；可复制，可下载 `.sh` / `.ps1`。**工具不会执行任何命令。**
   - ③ 参数比对：把命令输出填入「实测值」，自动标出与期待值不一致的项目，逐项点击 OK / NG，可导出 .xlsx。
   - ④ 交付物输出：把已知值写入客户模板并导出 .xlsx（保留原有格式），之后在 Excel 中手动编辑个性化部分。
4. **手顺执行**：v1 SOP Runner（拆分步骤、输入门控、备注/异常、Word 执行记录）。进度保存到本机 `data/` 文件夹。

### 检测规则（交付物模板）
| 检测来源 | 条件 |
|---|---|
| 占位符 | 单元格含 `{{name}}`、`＿＿＿`、`___`、`（　）`、`【　】` |
| 数据验证 | 单元格带数据验证：列表 → 下拉（支持 `"A,B"`、同表/其他表区域、名称定义）；整数/小数 → 数字（含最小/最大） |
| 底色 | 空单元格且有实心底色（非白色） |
| 标签旁空格 | 空单元格、带边框（或左侧标签以“：”结尾），左侧 6 列内有文字标签 |

标签 = 左侧最近的文字（行标签）＋ 上方表头（列标题；“設定値/値/内容”等通用词省略）。“備考/メモ/コメント”列默认可选且“不填”。类型推断：日期格式或“作業日”等 → 日期；数字格式或“GiB/サイズ/vCPU”等 → 数字。格式预设按标签推断（IP → IPv4，インスタンスID → `i-…`，AMI、サブネット、SG、ホスト名…）。

### 数据保存位置
`data/`（与 app.py 同一文件夹）：`library/`（上传的文件 + meta.json）、`jobs/*.json`、`sop_sessions/*.json`、`exports/`（导出的文件）。备份或迁移时复制整个 `data/` 即可。

### 安全
- 只绑定 127.0.0.1；校验 Host 头；每次启动生成随机 token，API 必须携带（防止其他网页跨站调用）。
- 所有页面资源都来自本机，CSP 禁止加载外部资源。测试中会断言没有任何外部网络请求。
- 生成的命令只作为文本；参数值含特殊字符时自动加引号；缺少 `--no-cli-pager`、`--output`、`-o BatchMode=yes`，或包含会修改资源的 aws 子命令、交互式程序、`rm`/`shutdown` 等时会显示警告。

## 日本語説明

### 動作環境
- Windows 10/11（macOS / Linux も可）、**Python 3.8 以上**（管理者権限・`pip install` 不要）
- ブラウザ：Edge / Chrome / Firefox
- ネットワーク不要。`127.0.0.1` のみで待ち受け、外部への通信は一切行いません。

### 起動方法
1. GitHub から ZIP をダウンロードして展開（または `git clone`）。
2. Windows は **`start.bat`** をダブルクリック。macOS は `start.command`、Linux は `./start.sh`。
3. ブラウザで `http://127.0.0.1:8765/` が自動で開きます（ポート使用中の場合は別ポート。黒い画面に URL が表示されます）。
4. 終了：画面右上の「退出」、または黒い画面で `Ctrl+C`。

### 使い方
1. **テンプレートライブラリ（模板库）**：成果物テンプレート（.xlsx）、パラメータシート（.xlsx：行＝項目、列＝サーバ）、手順書（.docx）、コマンドテンプレート集を登録します。「加载示例数据（虚构）」で架空サンプルを試せます。
2. **成果物テンプレートの編集**：参照するパラメータシートを選び「按标签自动映射（ラベルで自動マッピング）」。検出項目ごとにラベル・型（テキスト/数値/プルダウン/日付）・選択肢・必須・書式（IP、インスタンスID 等）・正規表現・最小/最大・記入元（作業入力／パラメータのキー／固定値／記入しない）を調整し、保存します。グリッドのセルをクリックすると検出漏れを追加できます。
3. **作業（作业）**：テンプレート・パラメータシート・対象サーバ・コマンド集・手順書を選んで作業を作成。
   - ① 入力チェック：ルール違反はリアルタイムで赤表示。パラメータシート側の値も同じルールでチェックします。
   - ② コマンド生成：`{{キー}}` をパラメータ値で置換した読み取り専用の確認コマンド。コピー、`.sh` / `.ps1` ダウンロード可。**ツールがコマンドを実行することはありません。**
   - ③ パラメータ照合：コマンド結果を「実測値」に入力すると期待値との不一致を自動表示。項目ごとに OK / NG を押し、.xlsx で出力できます。
   - ④ 成果物出力：既知の値を顧客テンプレートに記入して .xlsx 出力（書式は維持）。個別部分は Excel で手修正してください。
4. **手順実行（手顺执行）**：v1 SOP Runner（ステップ分割、入力が揃うまで確認不可、備考・異常フラグ、Word 実施記録）。進捗はローカルの `data/` に保存されます。

### データの保存場所
`data/` フォルダ（app.py と同じ場所）。バックアップ・移行は `data/` ごとコピーしてください。

测试 / テスト：`sh tests/run_all.sh`（单元测试只需 Python；E2E 需要 Node.js + Playwright，仅开发者使用）。

### 已知限制 / 既知の制限
- openpyxl 保存时**不保留**图片、图表、形状、文本框、宏（.xlsm 不支持）、部分高级条件格式/切片器；模板含这些对象时请先确认导出结果，或把图片类内容放在单独的文件里。
- 检测是启发式的：无边框的“表单”、竖排标签、跨多行的复杂表头需要在编辑器里手动补充/修正。
- 每个作业对应参数表中的一台服务器（多台服务器请建多个作业）。
- 比对的“实测值”需要从命令输出复制粘贴（不会自动执行命令或解析输出）。
- 手顺执行模块的限制同 v1（复杂 Word 版式、合并单元格等）。
